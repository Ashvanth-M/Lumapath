# LumaPath AI

> GUIDED INSIGHTS. STRONGER FUTURES.

LumaPath AI is an advanced application designed to capture and analyze multi-modal behavioral and interaction data. It leverages machine learning to process:

- 💬 **Communication**
- 🎙️ **Speech**
- 👁️ **Gaze**
- 🏃 **Gesture** (e.g. MediaPipe Hands pointing & reaching tracking)
- 👂 **Auditory Response**

## Development

You need Node.js and npm to run this project locally.

```sh
npm install
npm run dev
```

## Built With

- **TanStack Start**
- **TypeScript**
- **React**
- **Tailwind CSS**
- **TensorFlow.js / MediaPipe** (for on-device ML models)
